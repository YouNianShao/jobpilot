# JobPilot

作者：[YouNianShao](https://github.com/YouNianShao)

单机、单用户的多平台求职助手。在本机 Chrome 里用你自己的登录态完成：
**采集岗位 → AI 评分 → 生成招呼语 → 人工确认 → 自动投递 → 跟进**。

> 这是 JobPilot 的重写版。设计与需求见 [docs/](./docs)，从 [docs/01-功能需求.md](./docs/01-功能需求.md) 开始读。

## 与旧版（E:\JobPilot）的区别

| 项 | 旧版 | 新版 |
|---|---|---|
| Web | 标准库手写路由 | FastAPI + 四视图看板（概览 / 岗位池 / 监测 / 配置） |
| 浏览器 | 自研 Node CDP 桥 + 手写 JS | patchright 直连真实 Chrome（locator + 自动等待） |
| 前端 | 单文件 1257 行 | 原生 ES Modules 多文件（仍无构建） |
| 数据 | 无迁移 | SQLite WAL + 版本化迁移 |
| 平台扩展 | 改核心文件 | 只加一个驱动文件 |
| 防封号 | 只有每日投递上限 | 安全内核：活跃时段 + 页面预算 + 滚动窗口速率 + 按平台冷却锁 + 开页面节流 + 采集→投递冷却 + 熔断 + 按页不重复采 + 命中后降速 + 突发聚集惩罚 + 跨平台联动熔断 |

## 界面

侧栏 + 四视图，深色/浅色双主题：

- **概览**：「下一步」引导条（有新岗位就提示评分、有待确认就提示确认、有已确认就提示投递，按钮直接点）、4 张 KPI（今日投递进度 / 待确认 / 已确认 / 岗位池）、
  任务卡（进度 + 日志）、待确认队列（每条：岗位 + 分数 / 公司 · 薪资 · 平台 / 招呼语，右侧确认 · 拒绝；6 条一页）、
  **风控仪表**（每平台的剩余额度 + 冷却倒计时，平台名旁边写着它已核验能做什么）。
  历史、趋势、统计只放在「记录」页，概览不重复
- **岗位池**：全平台全量池，**服务端分页**（每页 50 条，默认最新采到的在最上面；筛选、搜索、排序、状态计数都对全量做）、按**状态 / 平台**分档一键筛选（每档带数量）、按 `/` 聚焦搜索、**勾选后批量确认 / 拒绝 / 移入回收站**（勾选跨页保留）、**点表头按 分数 / 公司 / 城市 / 状态 排序**、回收站、导出 CSV、点击看详情抽屉
- **监测**：**投递之后的进展看板** —— 顶部按状态汇总（已查看 / 已回复 / 约面试 / 面试完 / 拿到 offer / 被拒），
  下面按时间列出每个岗位的进展（点一行直接开详情），再加待跟进（一键生成跟进话术）。
  进展在岗位详情里手动记录。BOSS 的「只读聊天列表」监测已实现（不进会话、零副作用），
  但还没在真机上跑通完整任务，所以暂不声明能力、界面显示「未开放」；跑通后驱动会写进同一张表
- **记录**：**求职漏斗**（采到 → 打过分 → 过阈值 → 确认过 → 投出去，卡在哪一环一目了然）、
  **关键词效果**（每个词带来多少岗位 / 平均分 / 最高分 / 几个过线 —— 后面这句提示会直接告诉你该不该换词）、
  **公司分布**（同一家公司挂得越多，越可能是外包 / 中介 —— 和岗位性质识别互补，一个看话术、一个看数量）、
  今日开页面节奏（按小时柱状图，一眼看出节奏像不像人）、近 7 天用量、
  任务历史（含"停手原因"）、**风控事件**（命中验证码/限流、速率停手、页面异常都留痕）
- **配置**：按「模型 / 评分与筛选 / 简历与话术 / 投递 / 风控 / 浏览器与运行 / 平台」分组，保存条吸底；左侧有分组导航，字段按网格对齐；**边改边校验**（上下限直接来自后端的配置模型），保存前有问题会停在出错的字段上；平台在「平台」分组里直接切换，有未保存的修改会先提醒

快捷键只有两个：`/` 搜索岗位 · `Esc` 关闭弹层（以前的命令面板和 `g o` 这类两键快捷键已去掉：所有功能都有可见的按钮）

浏览器双击 **启动 JobPilot** 快捷方式即可（静默启动 + 自动开面板，不会留下控制台窗口）；关闭页面 2 分钟后服务自动退出。服务日志在 `data/serve.log`，启动失败时会弹出 `data/launch-failed.txt`（附这次启动之后的日志）。
看板**只接受本机访问**：别的网页没法读你的数据或替你点按钮（见 [06-风控与安全](docs/06-风控与安全.md) 第 6 节）。

> **页面 ≠ 任务**：关掉页面只是关掉"遥控器"，**正在跑的任务仍会在后台继续开页面/投递**
> （这是故意的：无人看管时也希望它能做完手头这一轮）。要让它停手，用右上角的「停止」——
> 它是软停止，做完当前这一个动作就在安全点退出，不会把动作打断到一半。

## 功能清单

- **采集**：BOSS直聘 / 前程无忧 / 猎聘 / 智联招聘；可选"打开详情页抓 JD"（会让评分更准，每岗多占一次详情页预算）
- **搜索关键词建议**：设置页里点一下，模型会读你的简历 + **你实际采到的岗位和评分**，
  给出"该搜什么 / 该避开什么"（它会直接引用你的数据，例如"AI —— 平均 20.2 分，全是销售岗"）
- **岗位性质识别**：采集回来的岗位会先按规则标记 **外包/派遣、培训招生、营销话术**（徽章显示在岗位池与详情里），
  岗位池可一键「只看正常岗」。默认**只标记不剔除**；想直接拦掉就在设置里填 `profile.block_natures`
- **模型服务商**：DeepSeek / 豆包 / 通义千问 / 智谱 GLM / Kimi / 硅基流动 / OpenAI / Claude / Gemini / 自定义（OpenAI 兼容，含本地 Ollama），配置页选服务商自动带出接口地址和推荐模型，一键「测试连接」（Key 只在本机面板里填，不经过别处）
- **评分**：AI 打分 + 评分理由 + 评分依据快照（模型 / prompt / token / 耗时），低于阈值直接沉底；**简历读不到时直接拒绝评分**，不允许拿空简历硬算
- **招呼语**：基于简历生成，可复制；自动跟进（默认投递 48h 后、最多 1 次、两次间隔 ≥72h、有回复即退出）
- **一键开跑**：采集直接用配置页里保存的关键词 / 城市 / 页数，不再每次弹框重填；顶栏的平台只管「采集 / 投递」（要开平台页面），
  「评分 / 招呼语」对所有平台的岗位一起处理。只有「投递」（会真的发出、撤不回）开跑前确认一次
- **人工确认门**：默认开启，投递前必须你点确认；可批量确认/拒绝。顺序是 采集（待评分）→ 评分过阈值（待确认）→ 你确认（已确认）→ 运行「投递」才真的发出；岗位池里勾了不能确认的岗位，会告诉你是哪几个、为什么（例如「还没评分」），并可直接去评分
- **简历**：配置页上传 **Word（.docx）/ PDF（需带文字层，扫描件会直接提示）/ Markdown / 纯文本**，支持拖拽；抽出的正文先进编辑框给你核对，点保存才生效。`profile.resume_path` 也可以直接指向 .docx / .pdf
- **定制简历**：按岗位重组真实经历，带防编造闸门（数字/单位必须能在原简历里找到）
- **投递**：只投已确认的岗位；每日上限 + 间隔随机 + 失败熔断。**BOSS直聘已实机核验、可自动投递**（点「立即沟通」时平台会先替你发出默认招呼语，随后再补一条 AI 生成的个性化招呼语）；其余三个平台仍走手动回执
- **面试准备**：对着这个岗位的 JD + 你的简历，生成 6-8 个面试问题和"该用哪段经历回答"，
  外加可能被追问的短板。**只引用简历里真实存在的经历**（没有的会写"如实说明"）；没有 JD 时会拒绝生成通用题清单
- **进展追踪**：投递之后手动记一笔 —— 已查看 / 已回复 / 约面试 / 面试完 / **拿到 offer** / 被拒；
  记录进「监测」页，并把求职漏斗延伸到面试与 offer（HR 监测未跑通之前，先把人的判断接住）
- **投递预演（只看不发）**：点一下就打开该岗位页，报告「沟通按钮在不在 / 是否要登录 / 有没有风控信号」，
  **不点、不发**。新平台要开放自动投递之前，先用这个攒证据（BOSS 就是这么开起来的）
- **手动投递回执**：还没开放自动投递的平台（51job / 猎聘 / 智联），一键「打开并复制招呼语」去平台上发，
  发完点「标记已投递」—— 状态、今日额度、跟进队列、统计立刻同步
  （手动和自动**共用同一套口径**，所以手动的次数也占额度）
- **回收站**：移入回收站直接做，提示里给「撤销」；恢复 / 彻底删除（只有彻底删除要二次确认）
- **备份**：设置页一键下载 zip（岗位库的**在线一致性快照** + config.yaml + 定制简历 + manifest）；
  恢复 = 停掉看板 → 解压覆盖同名文件 → 重启
- **导出**：CSV 一键导出岗位池

## 快速开始

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
copy config.example.yaml config.yaml      # 填 ai.api_key / 关键词 / 城市 / 简历路径
```

启动一个带远程调试的 Chrome 并登录目标平台，然后：

```bash
jobpilot serve                        # 打开看板（默认 http://127.0.0.1:8700）
jobpilot status                       # 看配置与各平台能力
jobpilot collect --platform boss      # 采集（风控闸门生效）
jobpilot score   --platform boss      # AI 评分 → 待确认
jobpilot greet   --platform boss      # 生成招呼语
jobpilot confirm --platform boss      # 人工确认
jobpilot apply   --platform boss      # 投递（只投已确认的）
jobpilot full    --platform boss      # 全流程（确认门开启时停在待确认）
jobpilot --help
```

接口契约见 [docs/04-接口契约.md](docs/04-接口契约.md)。

| `jobpilot check` | **系统体检**（命令行版，和顶栏「体检」同一套检查） |
| `python tools\smoke_e2e.py` | **端到端自检**：HTTP 打真接口走完整个生命周期（含真实模型调用），造合成岗位并在结尾清干净；加 `--via-shortcut` 会先从**桌面快捷方式**重启看板，把启动链也验掉 |
| `python tools\db_stats.py` | 数据库体检（表 / 计数 / demo 残留） |
| `python tools\seed_demo.py [--clear]` | 造/清演示数据（截图用，用完必须 `--clear`） |
| `node tools\cdp.mjs list\|open\|eval\|shot\|watch` | 极简 CDP 探针 |

## 风险提示

自动化操作招聘平台存在账号限制风险。本项目只做低频、保守、可停的操作，
不绕过验证码与登录墙。**自动投递默认是关闭的**，需要你在设置里显式打开（BOSS 已实机核验；其余三个平台尚未）。
平台反爬随时可能让某个动作失效，失效时的兜底永远是平台内手动投递。
